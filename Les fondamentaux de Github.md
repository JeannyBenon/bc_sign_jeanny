# Les fondamentaux de Github

## 1. Vocabulaire de base
- **Repository (Dépôt) :** Le dossier du projet.
- **Commit :** Une sauvegarde (photo) de l'état des fichiers.
- **Push :** Envoyer ses commits vers le serveur distant (GitHub).
- **Pull :** Récupérer le travail des autres.
- **Branch :** Une version parallèle du projet (ex: `main`, `dev`).

## 2. Commandes essentielles
- `git init` : Créer un nouveau dépôt.
- `git status` : Voir les changements en cours.
- `git add .` : Préparer tous les fichiers pour le commit.
- `git commit -m "message"` : Sauvegarder les changements.
- `git push origin branche` : Envoyer sur GitHub.
